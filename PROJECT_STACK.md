# ResumeIQ Proposal Stack Mapping

| Proposal Item | Implementation |
|---|---|
| Desktop Application | `desktop-javafx/` JavaFX Admin Command Center |
| Web Front-End | `frontend/` HTML + CSS + JavaScript + Bootstrap 5 |
| Web Back-End | `backend/` Node.js + Express.js |
| Database | `database/resumeiq.sql` MySQL schema |
| Version Control & Tools | Git/GitHub workflow + Figma design workflow |

Note: GitHub and Figma are project tools and therefore are not application runtime modules.


## UI Theme
The web interface uses a dark-purple glassmorphism sci-fi theme inspired by the supplied visual reference, with smooth hover, glow, sweep and entrance animations. Bootstrap 5.3.3 utilities and spinners are used alongside custom CSS.
