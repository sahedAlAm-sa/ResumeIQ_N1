# ResumeIQ JavaFX Desktop Application

This is the Desktop Application component required by the proposal.

## Requirements
- JDK 17+
- Maven

## Run in VS Code terminal
Open this folder in VS Code, then:

mvn javafx:run

The JavaFX app is an Admin Command Center with:
- Dashboard
- Users
- Jobs
- Applications
- Resume statistics

The web application remains in `../frontend` and the Node.js backend remains in `../backend`.
